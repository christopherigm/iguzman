The whole block is skipped when the order has no stored code (see `orders.services.qr`), so nothing here ever renders as a broken image. White background is explicit - a client in dark mode would otherwise invert the padding around the symbol and stop it scanning. {% endcomment %} {% if qr_cid %} {% comment %} 208px, up from 160 - the code is meant to be scanned off a phone screen at a counter, and the extra third is the difference between a reader that catches it at arm's length and one the customer has to hold still. It is `width` attribute *and* inline style, as every image in this message is: Outlook reads the attribute, everything else the style. Deliberately not `width:100%` - a QR stretched to a wide viewport gains nothing and loses its quiet zone against the padding. {% endcomment %}
